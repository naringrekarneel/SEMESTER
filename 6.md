# Similarity Measures in Information Retrieval

## 1. Introduction

In an Information Retrieval (IR) system, **similarity measures** are used to determine how similar a **user query** is to a document.

The basic idea is:

> **Higher similarity between query and document → higher chance of being relevant.**

Similarity measures are especially important in the **Vector Space Model**, where documents and queries are represented as vectors.

---

# 2. Common Similarity Measures

The major similarity measures used in IR are:

1. **Cosine Similarity**
2. **Euclidean Distance**
3. **Jaccard Similarity**
4. **Dice Similarity**
5. **Pearson Correlation**
6. **Manhattan Distance**

---

# 3. Cosine Similarity

### Definition

**Cosine similarity** measures the angle between two vectors rather than their physical distance.

It is one of the **most commonly used similarity measures in IR**.

### Formula

[
\boxed{
\text{Cosine Similarity}(Q,D)
=============================

\frac{Q\cdot D}
{|Q||D|}
}
]

Expanded:

[
\text{Cosine}(Q,D)
==================

\frac{\sum_{i=1}^{n}Q_iD_i}
{\sqrt{\sum_{i=1}^{n}Q_i^2}
\sqrt{\sum_{i=1}^{n}D_i^2}}
]

### Example

Suppose:

[
Q=(1,2,1)
]

[
D=(2,1,1)
]

Dot product:

[
Q\cdot D=(1)(2)+(2)(1)+(1)(1)=5
]

Magnitude:

[
|Q|=\sqrt{1^2+2^2+1^2}=\sqrt6
]

[
|D|=\sqrt{2^2+1^2+1^2}=\sqrt6
]

Therefore:

[
Cosine=\frac{5}{6}=0.833
]

So the documents are **highly similar**.

### Advantages

* Works well with high-dimensional text vectors.
* Independent of document length to a large extent.
* Commonly used with **TF-IDF**.

---

# 4. Euclidean Distance

Euclidean distance measures the **straight-line distance between two vectors**.

### Formula

[
\boxed{
d(Q,D)=\sqrt{\sum_{i=1}^{n}(Q_i-D_i)^2}
}
]

For example:

[
Q=(1,2)
]

[
D=(3,4)
]

[
d=\sqrt{(1-3)^2+(2-4)^2}
]

[
=\sqrt{4+4}
]

[
=\sqrt8\approx2.83
]

### Important point

For distance measures:

> **Smaller distance → more similar**

Unlike cosine similarity:

> **Higher value → more similar**

### Limitation

Euclidean distance can be affected by **document length and vector magnitude**, making it less suitable than cosine similarity for many text-retrieval tasks.

---

# 5. Jaccard Similarity

Jaccard similarity is commonly used when documents are represented as **sets of terms**.

### Formula

[
\boxed{
J(A,B)=\frac{|A\cap B|}
{|A\cup B|}
}
]

Where:

* (A) = terms in document/query A
* (B) = terms in document/query B

### Example

Suppose:

```text
A = {machine, learning, AI}

B = {machine, learning, data}
```

Common terms:

```text
A ∩ B = {machine, learning}
```

Union:

```text
A ∪ B = {machine, learning, AI, data}
```

Therefore:

[
J(A,B)=\frac{2}{4}=0.5
]

### Range

[
0 \leq J(A,B) \leq 1
]

* **0** → no common terms
* **1** → identical sets

---

# 6. Dice Similarity

Dice similarity is another set-based similarity measure.

### Formula

[
\boxed{
Dice(A,B)=
\frac{2|A\cap B|}
{|A|+|B|}
}
]

Using the previous example:

[
|A|=3,\quad |B|=3
]

[
|A\cap B|=2
]

Therefore:

[
Dice=\frac{2(2)}{3+3}
]

[
=\frac{4}{6}=0.667
]

A higher Dice score indicates greater similarity.

---

# 7. Pearson Correlation

Pearson correlation measures the **correlation between two vectors**.

### Formula

[
r=
\frac{\sum (Q_i-\bar Q)(D_i-\bar D)}
{\sqrt{\sum(Q_i-\bar Q)^2}
\sqrt{\sum(D_i-\bar D)^2}}
]

The value lies between:

[
-1 \leq r \leq 1
]

Interpretation:

| Value | Meaning                                 |
| ----- | --------------------------------------- |
| +1    | Perfect positive similarity/correlation |
| 0     | No linear correlation                   |
| -1    | Perfect negative correlation            |

It can be useful when the **pattern of term weights** is more important than their absolute values.

---

# 8. Manhattan Distance

Manhattan distance calculates the sum of the absolute differences between vector components.

### Formula

[
\boxed{
d(Q,D)=\sum_{i=1}^{n}|Q_i-D_i|
}
]

For:

[
Q=(1,2,3)
]

[
D=(2,4,1)
]

[
d=|1-2|+|2-4|+|3-1|
]

[
=1+2+2=5
]

Again:

> **Smaller distance → more similar.**

---

# 9. Comparison of Similarity Measures

| Measure                 | Type        | Basic Idea                           | Better Value |
| ----------------------- | ----------- | ------------------------------------ | ------------ |
| **Cosine Similarity**   | Vector      | Measures angle between vectors       | Higher       |
| **Euclidean Distance**  | Vector      | Straight-line distance               | Lower        |
| **Jaccard Similarity**  | Set         | Common terms / total unique terms    | Higher       |
| **Dice Similarity**     | Set         | Common terms relative to set sizes   | Higher       |
| **Pearson Correlation** | Statistical | Measures correlation between vectors | Higher       |
| **Manhattan Distance**  | Vector      | Sum of absolute differences          | Lower        |

---

# 10. Which One Is Most Common in IR?

**Cosine similarity** is particularly important in traditional IR because documents and queries are often represented as **TF-IDF vectors**.

For example:

```text
Query
  ↓
TF-IDF Vector
  ↓
Compare with document vectors
  ↓
Cosine Similarity
  ↓
Similarity Score
  ↓
Rank Documents
```

---

## 11. Conclusion

Similarity measures help an IR system determine **how closely a document matches a user's query**. Cosine similarity is widely used for vector-based text retrieval, while Jaccard and Dice are useful for set-based representations. Euclidean and Manhattan measure distance, where smaller values indicate greater similarity. The appropriate measure depends on how documents and queries are represented and the requirements of the retrieval system.

### Quick exam memory:

**Cosine → Angle**

**Euclidean → Straight-line distance**

**Jaccard → Intersection / Union**

**Dice → 2 × Intersection / Total size**

**Pearson → Correlation**

**Manhattan → Absolute differences**
