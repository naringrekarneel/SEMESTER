# Information Retrieval (IR) System — Architecture & Pipeline

## 1. Introduction

**Information Retrieval (IR)** is the process of finding **relevant information from a large collection of data** based on a user's query.

For example, when you search **“best laptops for students”** on Google, the IR system:

* understands your query,
* searches its collection/index,
* finds relevant documents,
* ranks them,
* and displays the most relevant results.

# 3. Main Components of an IR System

### 1. Document Collection

The system starts with a **large collection of documents**.

Examples:

* Web pages
* PDF files
* News articles
* Books
* Emails
* Research papers

```text
D = {D1, D2, D3, ..., Dn}
```

Each document contains text that needs to be processed and indexed.

---

### 2. Document Processing

Before searching, documents are converted into a standard form.

Common operations are:

#### a) Tokenization

Breaking text into individual words.

```text
"Deep learning is powerful"

        ↓

Deep | learning | is | powerful
```

#### b) Stop-word Removal

Common words that usually provide little searching value are removed.

```text
"the cat is on the table"

        ↓

"cat table"
```

Examples of stop words:

`the, is, a, an, on, of, and`

#### c) Stemming

Words are reduced to their basic stem.

```text
playing
played
plays

      ↓

play
```

#### d) Lemmatization

Words are converted to their proper dictionary form.

```text
better → good
running → run
```

---

### 3. Indexing

After preprocessing, the system creates an **index** so that documents can be searched quickly.

The most common structure is an **inverted index**.

Example:

```text
Term       Documents
──────────────────────
AI         D1, D3
Python     D1, D2
Learning   D1, D2, D3
```

Instead of scanning every document whenever a user searches, the system directly looks up the required terms in the index.

**This dramatically improves search speed.**

---

### 4. User Query

The user enters a search query.

Example:

```text
"machine learning applications"
```

The query is also processed using techniques such as:

* Tokenization
* Stop-word removal
* Stemming/lemmatization
* Normalization

So the query becomes suitable for matching against the index.

---

### 5. Query Processing

The processed query is compared with the indexed terms.

For example:

```text
Query:
"machine learning applications"

        ↓

machine
learning
application
```

The system searches the inverted index for these terms.

---

### 6. Retrieval / Matching

The IR system determines **which documents match the query**.

Different retrieval models can be used:

* **Boolean model**
* **Vector Space Model**
* **Probabilistic model**
* Modern systems may also use **neural/semantic retrieval**

For example:

```text
Query → "machine learning"

D1 → Machine learning tutorial       ✓
D2 → Deep learning applications      ✓
D3 → History of computers            ✗
```

---

### 7. Ranking

Usually, many documents match a query.

The system therefore needs to determine:

> **Which documents are most relevant?**

Documents are assigned a **relevance score** and sorted accordingly.

For example:

```text
Document       Score
─────────────────────
D5             0.92
D2             0.81
D7             0.64
D1             0.42
```

A common traditional technique is **TF-IDF**, while modern search engines may use sophisticated machine-learning and neural ranking methods.

---

### 8. Results Presentation

Finally, the ranked documents are presented to the user.

```text
Query: "machine learning"

1. Introduction to Machine Learning
2. Machine Learning Algorithms
3. Applications of Machine Learning
4. Machine Learning Tutorial
```

The goal is to place the **most relevant results at the top**.

---

# 4. Complete IR Pipeline

We can summarize the complete pipeline as:

```text
Documents
    ↓

    ↓
Indexing
    ↓
Inverted Index
    ↓
       ← User Query
             ↓
       Query Processing
             ↓
      Matching/Retrieval
             ↓
          Ranking

       Search Results
```

# 5. Example

Suppose we have three documents:

```text
D1 = "Python is used for machine learning"
D2 = "Java is used for web development"
D3 = "Python is popular in data science"
```

User searches:

```text
"Python machine learning"
```

### Step 1: Process query

```text
Python | machine | learning
```

### Step 2: Search index

The index identifies:

```text
Python   → D1, D3
machine  → D1
learning → D1
```

### Step 3: Matching

D1 contains all important query terms, so it gets a high relevance score.

### Step 4: Ranking

```text
1. D1  ← Most relevant
2. D3
```

### Step 5: Display

The user receives D1 first.

# 6. Important Points for 10 Marks

Remember this flow:

**Document Collection → Preprocessing → Indexing → Inverted Index → Query Processing → Matching → Ranking → Results**

### Key objectives of an IR system

* Retrieve **relevant** documents.
* Avoid irrelevant results.
* Provide results **quickly**.
* Rank the most useful documents at the top.
* Handle large-scale document collections efficiently.

### One-line conclusion

**An Information Retrieval system converts documents and user queries into searchable representations, retrieves matching documents using an IR model, ranks them according to relevance, and presents the best results to the user.**
