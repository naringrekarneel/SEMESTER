# Early Stopping — 7 Marks

## 1. Definition

**Early Stopping** is a regularization technique used during neural network training to **stop training before the model starts overfitting**.

The model is trained using the training data, while its performance is continuously monitored on a **validation dataset**.

The basic idea is:

[
\boxed{\text{Stop training when validation performance stops improving}}
]

---

## 2. Working Mechanism

During training, the model's performance typically behaves like this:

```text
Error
 ↑
 |\
 | \
 |  \ Training Error
 |   \________
 |            \
 |             \
 |        _____/ Validation Error
 |       /
 |      /
 +----------------------→ Epochs
              ↑
         Stop here
```

Initially:

* Training error decreases.
* Validation error also decreases.
* The model is learning useful patterns.

After some point:

* Training error continues decreasing.
* Validation error starts increasing.

This indicates **overfitting**.

Early stopping terminates training around the point where validation performance is best.

---

## 3. Steps of Early Stopping

### Step 1: Divide the data

Split the dataset into:

* Training set
* Validation set
* Test set

### Step 2: Train the model

Train the neural network for several epochs.

### Step 3: Monitor validation performance

After each epoch, calculate validation loss or another validation metric.

### Step 4: Detect lack of improvement

If validation loss stops improving for a specified number of epochs, called the **patience**, training is stopped.

### Step 5: Restore the best model

Usually, the weights from the epoch with the **lowest validation loss** are retained.

---

## 4. Example

Suppose validation loss is:

| Epoch | Validation Loss |
| ----: | --------------: |
|     1 |            0.80 |
|     2 |            0.65 |
|     3 |            0.52 |
|     4 |            0.45 |
|     5 |        **0.40** |
|     6 |            0.42 |
|     7 |            0.47 |
|     8 |            0.55 |

The lowest validation loss occurs at **Epoch 5**.

Although training may continue improving after Epoch 5, validation performance is getting worse.

Therefore, early stopping selects:

[
\boxed{\text{Epoch 5}}
]

as the best model.

---

## 5. How It Prevents Overfitting

Early stopping prevents the network from training excessively on the training dataset.

Without early stopping:

[
\text{More training}
\rightarrow
\text{memorization of training data}
\rightarrow
\text{overfitting}
]

With early stopping:

[
\text{Monitor validation}
\rightarrow
\text{detect overfitting}
\rightarrow
\text{stop training}
]

Thus, it limits the model's effective complexity.

---

## 6. Advantages

* Simple to implement.
* Prevents excessive training.
* Reduces overfitting.
* Saves training time and computational resources.
* Often improves performance on unseen data.
* Does not require modifying the network architecture.

---

## 7. Conclusion

**Early Stopping** is a regularization technique that monitors the model's performance on validation data during training. When validation performance stops improving or begins to worsen, training is stopped and the best-performing model is retained. It prevents the network from learning noise and memorizing the training data, thereby **reducing overfitting and improving generalization**.
