# Xavier (Glorot) and He Weight Initialization — 7 Marks

## 1. Introduction

**Weight initialization** is the process of assigning initial values to the weights of a neural network before training begins.

Poor initialization can cause:

* **Vanishing gradients**
* **Exploding gradients**
* Very slow convergence
* Unstable training

**Xavier (Glorot)** and **He initialization** are techniques designed to choose suitable initial weights so that activations and gradients remain at reasonable scales as they pass through the network.

---

# 2. Xavier (Glorot) Initialization

### Concept

**Xavier initialization** is mainly designed for networks using **symmetric activations**, especially **Sigmoid** and **Tanh**.

It chooses weights based on the number of input and output neurons.

Let:

* (n_{in}) = number of input neurons
* (n_{out}) = number of output neurons

A common Xavier normal formulation is:

[
\boxed{
W\sim N\left(0,\frac{2}{n_{in}+n_{out}}\right)
}
]

Therefore, the standard deviation is:

[
\boxed{
\sigma=\sqrt{\frac{2}{n_{in}+n_{out}}}
}
]

Another common form is Xavier uniform:

[
\boxed{
W\sim U\left(-\sqrt{\frac{6}{n_{in}+n_{out}}},
\sqrt{\frac{6}{n_{in}+n_{out}}}\right)
}
]

### Purpose

Xavier initialization attempts to maintain a reasonable variance of activations and gradients across layers.

---

# 3. He Initialization

### Concept

**He initialization**, also called **Kaiming initialization**, is specifically designed for networks using **ReLU and its variants**.

For ReLU, approximately half of the activations can become zero. Therefore, He initialization uses a larger variance than Xavier initialization.

The common He normal formulation is:

[
\boxed{
W\sim N\left(0,\frac{2}{n_{in}}\right)
}
]

Therefore:

[
\boxed{
\sigma=\sqrt{\frac{2}{n_{in}}}
}
]

A corresponding uniform version is:

[
\boxed{
W\sim U\left(-\sqrt{\frac{6}{n_{in}}},
\sqrt{\frac{6}{n_{in}}}\right)
}
]

---

# 4. Why Proper Initialization Is Important

Suppose the weights are extremely small:

[
W\approx0
]

Then activations and gradients may become very small:

[
\text{Vanishing gradients}
]

If weights are extremely large:

[
W\gg1
]

activations and gradients may become excessively large:

[
\text{Exploding gradients}
]

Good initialization attempts to keep values at a useful scale:

[
\boxed{
\text{Stable activations}
\rightarrow
\text{Stable gradients}
\rightarrow
\text{Faster training}
}
]

---

# 5. Xavier vs He Initialization

| Feature            | **Xavier (Glorot)**                   | **He (Kaiming)**                  |
| ------------------ | ------------------------------------- | --------------------------------- |
| Main activation    | Tanh, Sigmoid                         | ReLU, ReLU variants               |
| Depends mainly on  | (n_{in},n_{out})                      | (n_{in})                          |
| Common variance    | (\frac{2}{n_{in}+n_{out}})            | (\frac{2}{n_{in}})                |
| Main goal          | Maintain activation/gradient variance | Account for ReLU's zeroing effect |
| Training stability | Good for symmetric activations        | Excellent for ReLU networks       |

---

# 6. Example

Suppose a layer has:

[
n_{in}=100,\qquad n_{out}=50
]

### Xavier

[
\sigma=
\sqrt{\frac{2}{100+50}}
]

[
\sigma\approx0.115
]

### He

[
\sigma=
\sqrt{\frac{2}{100}}
]

[
\sigma\approx0.141
]

Thus, He initialization generally uses a larger initial variance for this example.

---

# 7. Significance

Proper weight initialization:

* Prevents extremely large or small activations.
* Helps reduce vanishing/exploding gradients.
* Improves convergence speed.
* Makes deep networks easier to train.
* Provides a suitable starting point for gradient-based optimization.

### Easy way to remember

[
\boxed{\text{Xavier} \rightarrow \text{Sigmoid/Tanh}}
]

[
\boxed{\text{He} \rightarrow \text{ReLU}}
]

## Conclusion

**Xavier initialization** chooses weights to maintain a suitable variance of activations and gradients and is commonly used with **Sigmoid and Tanh**. **He initialization** uses a larger variance, accounting for the behavior of **ReLU**, and is therefore preferred for ReLU-based deep networks. Both techniques improve training stability, convergence, and gradient flow.
