# L1 (Lasso) vs L2 (Ridge) Regularization

## 1. Introduction

**Regularization** is a technique used to reduce **overfitting** by adding a penalty to the loss function. Two common techniques are:

* **L1 Regularization (Lasso)**
* **L2 Regularization (Ridge)**

Both discourage large weights, but they do so differently.

---

## 2. L1 Regularization — Lasso

L1 adds the **absolute value of the weights** to the loss function:

[
\boxed{
L_{L1}=L+\lambda\sum_i|w_i|
}
]

The weight update is:

[
\boxed{
w_i\leftarrow w_i-\eta
\left(
\frac{\partial L}{\partial w_i}
+\lambda,sign(w_i)
\right)
}
]

### Main effect

L1 tends to push some weights **exactly to zero**.

For example:

[
[0.8,;0.03,;-0.02,;0.7]
]

may become:

[
[0.8,;0,;0,;0.7]
]

Therefore:

[
\boxed{\text{L1} \rightarrow \text{Sparse model}}
]

It can also perform **feature selection** by eliminating unimportant features.

---

## 3. L2 Regularization — Ridge

L2 adds the **squared values of weights** to the loss:

[
\boxed{
L_{L2}=L+\frac{\lambda}{2}\sum_iw_i^2
}
]

The weight update is:

[
\boxed{
w_i\leftarrow
w_i-\eta
\left(
\frac{\partial L}{\partial w_i}
+\lambda w_i
\right)
}
]

L2 continuously shrinks weights toward zero but generally **does not make them exactly zero**.

Therefore:

[
\boxed{\text{L2} \rightarrow \text{Small, distributed weights}}
]

---

## 4. Comparison

| Feature           | **L1 (Lasso)**                   | **L2 (Ridge)**                             |   |                               |
| ----------------- | -------------------------------- | ------------------------------------------ | - | ----------------------------- |
| Penalty           | (\lambda\sum                     | w_i                                        | ) | (\frac{\lambda}{2}\sum w_i^2) |
| Weight effect     | Drives some weights to exactly 0 | Shrinks weights toward 0                   |   |                               |
| Sparsity          | **Yes**                          | Usually no                                 |   |                               |
| Feature selection | Yes                              | No direct feature selection                |   |                               |
| Gradient          | (\lambda sign(w))                | (\lambda w)                                |   |                               |
| Best suited for   | Sparse models                    | Stable/general weight shrinkage            |   |                               |
| Large weights     | Penalized                        | Penalized more strongly as magnitude grows |   |                               |

---

## 5. Simple Intuition

Think of the weights as items in a backpack.

**L1:**

> "Remove unnecessary items completely."

So some weights become **zero**.

**L2:**

> "Keep everything, but make the heavy items lighter."

So weights become **smaller**, but usually remain non-zero.

---

## 6. Key Difference

The most important exam point is:

[
\boxed{
\text{L1} \Rightarrow \text{Sparse weights}
}
]

[
\boxed{
\text{L2} \Rightarrow \text{Small weights}
}
]

### Conclusion

L1 (Lasso) and L2 (Ridge) both reduce overfitting by penalizing large weights. **L1 uses the absolute value of weights and tends to produce sparse models by making some weights exactly zero**, while **L2 uses squared weights and smoothly shrinks weights toward zero**. Thus, L1 is useful when feature selection and sparsity are desired, whereas L2 is useful when we want stable models with small, distributed weights.
