# Dropout During Training and Inference — 7 Marks

## 1. Introduction

**Dropout** is a regularization technique used in neural networks to reduce **overfitting**.

During training, Dropout randomly **deactivates a fraction of neurons**. This prevents the network from depending too heavily on particular neurons and encourages it to learn more robust features.

During inference, **Dropout is disabled**, and the complete network is used.

---

## 2. Dropout During Training

Suppose a neural network contains several neurons:

```text
Before Dropout:

●   ●   ●   ●   ●
 \ / \ / \ / \ /
  ●   ●   ●   ●

After Dropout:

●   ✕   ●   ●   ✕
 \   \ /   \ /
  ●   ✕   ●   ●
```

Some neurons are randomly switched off in each training iteration.

### Step 1: Generate a random mask

For each neuron, a binary mask is generated:

[
\boxed{
m_i\sim Bernoulli(1-p)
}
]

where:

* (p) = probability of dropping a neuron
* (1-p) = probability of keeping it

For example, if:

[
p=0.5
]

approximately 50% of the neurons are kept and 50% are dropped on average.

---

### Step 2: Apply the mask

If (h_i) is the activation of a neuron:

[
\tilde{h}_i=m_i h_i
]

With **inverted dropout**, which is commonly used:

[
\boxed{
\tilde{h}_i=\frac{m_i h_i}{1-p}
}
]

The division by (1-p) keeps the expected activation approximately unchanged.

---

### Step 3: Forward and Backward Propagation

The network performs:

[
\text{Forward Propagation}
\rightarrow
\text{Loss}
\rightarrow
\text{Backpropagation}
\rightarrow
\text{Weight Update}
]

Dropped neurons do not contribute to that particular forward/backward pass.

A new random mask is generally generated in the next iteration.

---

# 3. Dropout During Inference

During **testing or inference**, Dropout is **turned off**.

No neurons are randomly removed.

The complete network is used:

```text id="i3iv4r"
Training:

●   ●   ✕   ●   ✕
 \ /     \ /
  ●   ✕   ●

Random neurons removed


Inference:

●   ●   ●   ●   ●
 \ / \ / \ / \ /
  ●   ●   ●   ●

All neurons active
```

With inverted dropout, **no additional scaling is required during inference**, because the scaling by (1/(1-p)) was already performed during training.

---

# 4. Why Dropout Prevents Overfitting

Without Dropout, the network may become overly dependent on particular neurons.

For example:

[
\text{Neuron A} \rightarrow \text{important feature}
]

The network may rely heavily on Neuron A.

With Dropout, Neuron A may randomly disappear during training.

Therefore, the network must learn to use other neurons as well.

[
\boxed{
\text{Dropout}
\rightarrow
\text{less neuron dependency}
\rightarrow
\text{better generalization}
}
]

It can be viewed as training many different subnetworks that share parameters.

---

# 5. Training vs Inference

| Feature                       | **Training**        | **Inference**         |
| ----------------------------- | ------------------- | --------------------- |
| Dropout                       | Enabled             | Disabled              |
| Neurons                       | Randomly dropped    | All active            |
| Random mask                   | Generated           | Not used              |
| Weight updates                | Yes                 | No                    |
| Purpose                       | Prevent overfitting | Make predictions      |
| Scaling with inverted dropout | During training     | No additional scaling |

---

# 6. Example

Suppose a layer has **10 neurons** and:

[
p=0.3
]

Then approximately:

[
30% \rightarrow \text{dropped}
]

[
70% \rightarrow \text{kept}
]

With inverted dropout, the retained activations are scaled by:

[
\frac{1}{1-p}
=============

\frac{1}{0.7}
\approx1.43
]

During inference, all 10 neurons are active and no dropout scaling is needed.

---

## 7. Conclusion

**Dropout** randomly deactivates neurons during training using a probability (p), forcing the network to learn robust and distributed representations. In commonly used **inverted dropout**, the surviving activations are scaled by (1/(1-p)) during training. During inference, Dropout is disabled and all neurons are used, with no additional scaling required. Thus, Dropout reduces **overfitting** and improves the model's ability to generalize to unseen data.
