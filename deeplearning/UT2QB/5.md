# Grid Search vs Random Search — 7 Marks

## 1. Introduction

**Hyperparameter tuning** is the process of finding the best values of hyperparameters such as learning rate, batch size, number of hidden layers, and regularization strength.

Two common methods are:

1. **Grid Search**
2. **Random Search**

Both methods train the model with different hyperparameter combinations and select the combination that gives the best validation performance.

---

# 2. Grid Search

### Definition

**Grid Search** systematically tests **every possible combination** of predefined hyperparameter values.

For example:

* Learning rate: ({0.01,0.001})
* Batch size: ({32,64})
* Number of layers: ({2,3})

Total combinations:

[
2\times2\times2=8
]

Grid Search tests all 8 combinations.

### Working

```text
Hyperparameter values
        ↓
Generate all combinations
        ↓
Train model for each combination
        ↓
Evaluate validation performance
        ↓
Select best combination
```

### Advantages

* Simple and systematic.
* Guarantees that every specified combination is tested.
* Works well when the search space is small.

### Disadvantages

* Can be computationally expensive.
* Becomes inefficient when many hyperparameters are involved.
* May spend a lot of time testing unimportant combinations.

---

# 3. Random Search

### Definition

**Random Search** randomly selects hyperparameter combinations from predefined ranges or distributions.

For example:

[
Learning\ Rate\sim[0.0001,0.1]
]

[
Batch\ Size\in{16,32,64,128}
]

Instead of testing every possible combination, Random Search tests a fixed number of randomly selected combinations.

### Working

```text
Hyperparameter ranges
        ↓
Randomly select combinations
        ↓
Train models
        ↓
Evaluate validation performance
        ↓
Select best combination
```

### Advantages

* Usually more computationally efficient.
* Can explore a large search space.
* Often finds good hyperparameters faster than Grid Search.
* Especially useful when only a few hyperparameters strongly affect performance.

### Disadvantages

* Does not guarantee that the best combination will be tested.
* Results can vary depending on random sampling.
* Requires choosing the number of random trials.

---

# 4. Comparison

| Feature             | **Grid Search**                  | **Random Search**                   |
| ------------------- | -------------------------------- | ----------------------------------- |
| Search method       | Systematic                       | Random                              |
| Combinations tested | All specified combinations       | Selected random combinations        |
| Computational cost  | Usually higher                   | Usually lower                       |
| Search space        | Better for small spaces          | Better for large spaces             |
| Guarantee           | Tests every grid combination     | No guarantee                        |
| Efficiency          | Can waste trials                 | Often more efficient                |
| Reproducibility     | High                             | Depends on random seed              |
| Best use            | Small, well-defined search space | Large/high-dimensional search space |

---

# 5. Example

Suppose we have three hyperparameters:

[
Learning\ Rate={0.1,0.01,0.001}
]

[
Batch\ Size={32,64,128}
]

[
Dropout={0.2,0.5}
]

Grid Search requires:

[
3\times3\times2=\boxed{18}
]

experiments.

Random Search might test only:

[
\boxed{5\text{ or }10}
]

random combinations.

Therefore, Random Search can reach a good solution with fewer experiments.

---

# 6. Why Random Search Can Be More Efficient

Suppose only the **learning rate** has a major effect on model performance, while batch size has relatively little effect.

Grid Search spends many experiments testing different batch sizes for every learning rate.

Random Search spreads its trials across the search space and is more likely to explore useful values of the important hyperparameter.

Thus:

[
\boxed{
\text{Random Search often gives better results per computation}
}
]

---

## 7. Conclusion

**Grid Search** exhaustively evaluates every predefined combination of hyperparameters and is suitable for small search spaces. **Random Search** randomly samples combinations and is generally more efficient for large or high-dimensional search spaces. Grid Search provides systematic coverage, while Random Search often finds good hyperparameter values with fewer training experiments.
