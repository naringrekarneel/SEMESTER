# Bagging, Snapshot Ensembles, and Stochastic Weight Averaging (SWA) — 10 Marks

## 1. Introduction

**Ensemble Learning** is a machine learning paradigm that combines multiple models, diverse training states, or parameter sets to improve predictive accuracy, stability, and out-of-distribution generalization.

While traditional neural network training converges to a single point estimate in parameter space, ensemble and averaging techniques explore multiple regions of the non-convex loss landscape. Three prominent methodologies spanning distinct computational trade-offs are:
1. **Bagging (Bootstrap Aggregating):** Trains independent models on resampled datasets in parallel.
2. **Snapshot Ensembles:** Gathers multiple diverse model states along a single training trajectory using cyclic learning rates.
3. **Stochastic Weight Averaging (SWA):** Directly averages model weights in parameter space to find wide, flat, robust minima with zero inference overhead.

## 2. Bagging (Bootstrap Aggregating)

```text
               Original Training Dataset D (N samples)
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
  Bootstrap D_1            Bootstrap D_2            Bootstrap D_M
  (N with replace)         (N with replace)         (N with replace)
         │                        │                        │
         ▼                        ▼                        ▼
     Model M_1                Model M_2                Model M_M
  (Independent)            (Independent)            (Independent)
         │                        │                        │
         └────────────────────────┬────────────────────────┘
                                  ▼
                   Aggregation Mechanism (Vote / Average)
                                  ▼
                            Final Output ŷ
```

### Definition & Principle
**Bagging** (Leo Breiman, 1996) creates an ensemble of $M$ diverse models by training each base estimator independently on a distinct bootstrap sample of the training data. A **bootstrap sample** is constructed by drawing $N$ examples uniformly at random from the original dataset of size $N$ **with replacement** (approximately $63.2\%$ unique samples per set, with $36.8\%$ out-of-bag).

### Mathematical Aggregation:
* **Regression (Continuous):** Predictions are averaged across all $M$ models:
  $$\hat{y}(x) = \frac{1}{M} \sum_{m=1}^{M} \hat{y}_m(x)$$
* **Classification (Discrete):** Aggregated via majority voting or softmax probability averaging:
  $$\hat{y}(x) = \operatorname{argmax}_{c} \frac{1}{M} \sum_{m=1}^{M} P_m(y = c \mid x)$$

### Variance Reduction Mechanism:
If each individual model has variance $\sigma^2$ and the models have pairwise correlation $\rho$, the ensemble variance is:
$$\operatorname{Var}(\text{Ensemble}) = \rho \sigma^2 + \frac{1 - \rho}{M} \sigma^2$$
As $M \to \infty$, the second term approaches zero. If models are completely uncorrelated ($\rho = 0$), variance shrinks to $\frac{\sigma^2}{M}$.

### Pros & Cons:
* **Advantages:** Effectively prevents overfitting on high-variance models (e.g., decision trees $\to$ Random Forests; unregularized MLPs).
* **Limitations:** Multiplies computational cost and GPU memory by $M\times$. Training $M$ deep neural networks from scratch is often computationally prohibitive.

## 3. Snapshot Ensembles

```text
Learning Rate η
     │
η_0  ├─╲       ╱╲       ╱╲       ╱╲
     │  ╲     ╱  ╲     ╱  ╲     ╱  ╲
     │   ╲   ╱    ╲   ╱    ╲   ╱    ╲
 0   └─── S_1 ──── S_2 ─── S_3 ─── S_4 ───► Epochs
           ▲        ▲       ▲        ▲
      (Snapshot) (Snapshot)(Snapshot)(Snapshot)
```

### Definition & Principle
Introduced by Huang et al. (2017), **Snapshot Ensembles** obtain the benefits of an ensemble **at the cost of training a single neural network once**.

Instead of training $M$ separate networks from random seeds, a single network is trained using a **Cyclic Cosine Annealing Learning Rate Schedule**. The learning rate periodically resets to a high value and gradually drops to zero:

$$\eta(t) = \frac{\eta_0}{2} \left( \cos\left( \frac{\pi \cdot \operatorname{mod}(t-1, \lceil T/M \rceil)}{\lceil T/M \rceil} \right) + 1 \right)$$

where:
* $t$ = current iteration / epoch.
* $T$ = total training epochs.
* $M$ = number of cycles (snapshots).
* $\eta_0$ = initial maximum learning rate.

### Working Mechanism:
1. **Annealing (Exploitation):** As $\eta \to 0$, the optimizer converges into a local minimum. Just before the cycle ends, the model weights are saved as a **Snapshot** ($S_m$).
2. **Warm Restart (Exploration):** The learning rate abruptly jumps back to $\eta_0$. This large gradient step gives the optimizer sufficient kinetic energy to escape the current basin of attraction.
3. **New Basin:** The optimizer falls into an entirely different, diverse local minimum.
4. **Inference Aggregation:** Predictions from the $M$ saved snapshots are combined at test time via probability averaging:
   $$P_{\text{ensemble}}(y \mid x) = \frac{1}{M} \sum_{m=1}^{M} P_{S_m}(y \mid x)$$

### Pros & Cons:
* **Advantages:** "Free" ensemble training; provides substantial accuracy boosts with zero additional training FLOPs compared to a standard training run.
* **Limitations:** Requires storing $M$ distinct checkpoints on disk; test-time inference latency is multiplied by $M\times$.

## 4. Stochastic Weight Averaging (SWA)

```text
Loss Surface Contour Map
────────────────────────────────────────────────────────────────
        \          SWA Minimum (Flat, Wide Basin)       /
         \                      ★                      /
          \                  w_SWA                    /
           \              ╱    │    ╲                /
            \          w_1    w_2    w_3            /
             \          •      •      •            /
              \   SGD Checkpoints Along Trajectory/
────────────────────────────────────────────────────────────────
```

### Definition & Principle
Proposed by Izmailov et al. (2018), **Stochastic Weight Averaging (SWA)** averages the **weights** of a single neural network visited along an SGD trajectory with a cyclical or constant learning rate, rather than ensembling output predictions.

### Geometric Intuition: Flat vs. Sharp Minima
* Standard SGD with learning rate decay typically stops near the **edge / boundary** of a wide flat region or gets trapped in a **sharp minimum**.
* Sharp minima generalize poorly: small shifts between the training distribution and test distribution cause large spikes in test error.
* SWA exploits the observation that SGD with a sustained learning rate orbits around the periphery of flat regions. Averaging these weights geometrically places the final solution **directly in the center of the wide, flat basin**, leading to optimal out-of-distribution generalization.

### Mathematical Formulation:
Weights are collected after a warmup threshold ($T_{\text{start}}$) every $c$ epochs:

$$w_{\text{SWA}} = \frac{1}{K} \sum_{i=1}^{K} w_i$$

In practice, this is implemented as an online running average:

$$w_{\text{SWA}} \leftarrow \frac{w_{\text{SWA}} \cdot n_{\text{models}} + w_{\text{current}}}{n_{\text{models}} + 1}$$

### Mandatory Step: BatchNorm Recalibration
Because weights are averaged directly, intermediate activation statistics change. Before inference, the network must perform a single forward pass over the training data with fixed weights $w_{\text{SWA}}$ to recalculate the running mean ($\mu$) and variance ($\sigma^2$) for all **Batch Normalization** layers.

### Pros & Cons:
* **Advantages:** **ZERO inference overhead** (the final model is a single standard network with identical latency and memory footprint to a single checkpoint); finds flatter minima and significantly improves generalization.
* **Limitations:** Requires running the BatchNorm recalibration pass; only effective when checkpoints originate from the same basin of attraction or connected flat valleys.

## 5. Comprehensive Comparison Table

| Feature / Dimension | Bagging | Snapshot Ensembles | Stochastic Weight Averaging (SWA) |
| :--- | :--- | :--- | :--- |
| **What is Combined?** | Output **Predictions** | Output **Predictions** | Model **Weights** ($W$) |
| **Number of Base Networks**| $M$ distinct networks | 1 network (saved at $M$ points) | 1 network (averaged parameters) |
| **Data Partitioning** | Bootstrap resamples with replacement | Identical full training dataset | Identical full training dataset |
| **Optimization Strategy** | Standard training for each model | Cyclic learning rate restarts | Constant / Cyclical LR exploration |
| **Training Computation** | Extremely High ($M \times \text{Cost}$) | Standard ($1 \times \text{Cost}$) | Standard + 1 BN pass ($1 \times \text{Cost}$) |
| **Inference Cost / Latency** | $M\times$ forward passes | $M\times$ forward passes | **$1\times$ forward pass (Zero overhead!)** |
| **Disk Storage Footprint** | $M$ complete checkpoints | $M$ complete checkpoints | **1 single final checkpoint** |
| **Mechanism of Gain** | Variance reduction over data noise | Multiple diverse local minima | Convergence to wide, flat minima |

## 6. Practical Use-Case Scenarios

```text
                                DECISION MATRIX
                                       │
     ┌─────────────────────────────────┼─────────────────────────────────┐
     ▼                                 ▼                                 ▼
High Compute & Memory?       Need Diversity on 1 GPU?         Zero Latency at Inference?
  Use BAGGING                  Use SNAPSHOT ENSEMBLES            Use SWA
(Random Forests, MLPs)         (Kaggle, Offline Batch)          (Production APIs, Edge Devices)
```

1. **Bagging:** Best suited for high-variance tabular models or when massive cluster compute allows parallel training of independent networks.
2. **Snapshot Ensembles:** Ideal for competitive machine learning benchmarks (e.g., Kaggle) where inference latency is secondary to maximizing ensemble accuracy.
3. **Stochastic Weight Averaging (SWA):** The industry standard for production environments, real-time APIs, and mobile edge deployment where memory constraints mandate a **single model** with enhanced generalization.

---

## 7. Conclusion

Modern deep learning offers diverse techniques to harvest the benefits of ensemble learning:
* **Bagging** reduces predictive variance by training independent models on resampled subsets of the data.
* **Snapshot Ensembles** capture diverse prediction states along a single training run via cyclic learning rate restarts without training multiple models from scratch.
* **Stochastic Weight Averaging (SWA)** averages parameters directly to locate wide, flat minima, delivering ensemble-level generalization inside a **single model with zero additional test-time latency**.

## Quick Revision for Exams

* **Bagging:** Resample data $\to$ train $M$ models $\to$ average predictions ($M\times$ training and test cost).
* **Snapshot Ensembles:** Cyclic LR $\to$ save $M$ snapshots near minima $\to$ average predictions ($1\times$ training cost, $M\times$ test cost).
* **SWA:** Collect weights during high/cyclic LR $\to$ average weights directly $\to$ recalculate BatchNorm $\implies$ **$1\times$ single model at test time!**

### 🧠 One-line memory trick
> **Bagging averages different models, Snapshots average different checkpoints' predictions, and SWA averages the weights themselves!**
