### Q. Analyze the Various Activation Functions Used in Convolutional Neural Networks (CNN). (10 Marks)

### 1\. Introduction

An activation function is a mathematical function applied to the output of a neuron in a Convolutional Neural Network (CNN). It introduces non-linearity, allowing the network to learn complex patterns and relationships in data.

Without activation functions, multiple neural network layers would behave like a single linear transformation, limiting the network's ability to recognize complex features such as edges, textures, shapes and objects.

### 2\. Types of Activation Functions

### 1\. Sigmoid Activation Function

The sigmoid function converts input values into a range between 0 and 1.

Formula:

$$ f(x)=\\frac1 $$

Sigmoid function: S-shaped curve

Advantages:

* Useful for binary classification.

* Produces outputs that can be interpreted as probabilities.

Limitations:

* Suffers from the vanishing gradient problem.

* Not zero-centered, which can slow training.

Application: Commonly used in the output layer for binary classification.

### 2\. Tanh (Hyperbolic Tangent)

The Tanh function maps input values between -1 and 1.

Formula:

$$ f(x)=\\frac $$

Tanh function: zero-centered S-shaped curve

Advantages:

* Zero-centered output.

* Provides stronger gradients than sigmoid near zero.

Limitations:

* Suffers from vanishing gradients for large positive or negative inputs.

* Computationally more expensive than ReLU.

Application: Used in some hidden layers and recurrent neural networks.

### 3\. ReLU (Rectified Linear Unit)

ReLU is one of the most widely used activation functions in CNNs. It outputs zero for negative inputs and returns the input itself for positive values.

Formula:

$$ f(x)=\\max(0,x) $$

ReLU function

Advantages:

* Simple and computationally efficient.

* Reduces the vanishing gradient problem for positive inputs.

* Encourages sparse activation because negative inputs become zero.

Limitations:

\- Suffers from the dying ReLU problem, where neurons may permanently output zero.

Application: Commonly used in convolutional and fully connected hidden layers.

### 4\. Leaky ReLU

Leaky ReLU is a modified version of ReLU that allows a small negative output instead of setting all negative inputs to zero.

Formula:

$$ f(x)= \\begin x & x>0\\ \\alpha x & x\\leq 0 \\end $$

Here, $\\alpha$ is a small positive constant, such as 0.01.

Leaky ReLU: small negative slope

Advantages:

* Reduces the dying ReLU problem.

* Allows gradients to flow for negative inputs.

Limitations:

* Requires selecting an appropriate value of $\\alpha$.

* Does not always outperform standard ReLU.

Application: Used in deep CNNs, including some image generation models.

### 5\. ELU (Exponential Linear Unit)

ELU uses an exponential function for negative inputs and a linear function for positive inputs.

Formula:

$$ f(x)= \\begin x & x>0\\ \\alpha(e^x-1) & x\\leq 0 \\end $$

Advantages:

* Produces smooth negative outputs.

* Can improve convergence compared with ReLU in some networks.

* Reduces the risk of inactive neurons.

Limitations:

\- Computationally more expensive due to the exponential operation.

Application: Used in deep CNNs where smoother activation is beneficial.

### 3\. Comparison of Activation Functions

| Function   | Output range            | Main characteristic       | Typical use            |
| ---------- | ----------------------- | ------------------------- | ---------------------- |
| Sigmoid    | 0 to 1                  | Probability-like output   | Binary classification  |
| Tanh       | -1 to 1                 | Zero-centered             | Selected hidden layers |
| ReLU       | 0 to $\\infty$          | Fast and simple           | CNN hidden layers      |
| Leaky ReLU | $-\\infty$ to $\\infty$ | Allows negative gradients | CNN hidden layers      |
| ELU        | $-\\alpha$ to $\\infty$ | Smooth negative region    | Deep CNN hidden layers |
| Softmax    | 0 to 1                  | Multi-class probabilities | Output layer           |

### 4\. Conclusion

Activation functions are essential for introducing non-linearity into CNNs and enabling them to learn complex image features. ReLU is a common default for hidden layers because of its simplicity and computational efficiency. Leaky ReLU and ELU provide alternatives when standard ReLU causes training difficulties. Sigmoid and Softmax are commonly used in output layers for binary and multi-class classification, respectively.
