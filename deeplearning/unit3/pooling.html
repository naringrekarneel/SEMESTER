Topic 2: Padding

Padding is the next piece of the CNN puzzle. It solves an important problem caused by convolution: the image gets smaller every time we apply a filter.

1. Padding — ELI5

Imagine you have a photo and you're putting a frame around it before applying a filter.

That extra border is padding.

Instead of letting the convolution filter operate only inside the original image, we add extra pixels around the edges.

Usually, these added pixels are zeros, so this is called zero padding.

Why do we need it?

  • Without padding: Input → Convolution → Smaller output
  • With padding: Input → Padding → Convolution → Same-size or controlled output

2. Why is padding necessary?

There are two major reasons:

Reason 1: Prevent excessive reduction in image size

Suppose:

  • Input = $5 \times 5$
  • Kernel = $3 \times 3$
  • Stride = $1$
  • Padding = $0$

$$O = \frac{5 - 3 + 2(0)}{1} + 1 = 3$$

So: $5 \times 5 \rightarrow 3 \times 3$. If we repeatedly perform convolution without padding, the feature map rapidly shrinks down to nothing.

Reason 2: Preserve information at the edges

Consider a filter scanning an image:

  • Pixels in the center participate in many overlapping convolution steps.
  • Pixels near the corners and edges participate in far fewer operations.

Without padding, boundary information is underrepresented. Padding gives those outer pixels equal opportunity to contribute to high-level features.

3. Types of Padding

  1. Valid Padding ($P = 0$): No padding is added. Output contracts spatially.
    Example: $5 \times 5 \rightarrow 3 \times 3$
  2. Same Padding: Zero layers added so that output spatial dimensions equal input dimensions when $S = 1$.
    Example: $5 \times 5 \rightarrow 5 \times 5$

4. Visual Intuition

Original $3 \times 3$ matrix:

1  2  3
4  5  6
7  8  9

With zero padding of $P = 1$ (expanded to $5 \times 5$):

0  0  0  0  0
0  1  2  3  0
0  4  5  6  0
0  7  8  9  0
0  0  0  0  0

5. How Much Padding is Required?

For an odd kernel size ($K$) with stride $S = 1$, the padding needed for Same Padding is:

$$P = \frac{K - 1}{2}$$

  • For a $3 \times 3$ kernel: $P = \frac{3 - 1}{2} = 1$ layer
  • For a $5 \times 5$ kernel: $P = \frac{5 - 1}{2} = 2$ layers

6. Output-Size Formula

$$O = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1$$
Symbol Meaning
$N$Input dimension (width/height)
$K$Kernel dimension
$P$Padding applied to each border
$S$Stride step size
$O$Output dimension

7. Worked Examples

Example 1: No Padding (Valid)

Given $N = 7$, $K = 3$, $P = 0$, $S = 1$:

$$O = \frac{7 + 2(0) - 3}{1} + 1 = 5 \implies 7 \times 7 \rightarrow 5 \times 5$$

Example 2: Same Padding

Given $N = 7$, $K = 3$, $P = 1$, $S = 1$:

$$O = \frac{7 + 2(1) - 3}{1} + 1 = 7 \implies 7 \times 7 \rightarrow 7 \times 7$$

Example 3: Comparison at $N = 32$, $K = 3$, $S = 1$

Padding Scheme $P$ Value Input Output
Valid $P = 0$ $32 \times 32$ $30 \times 30$
Same $P = 1$ $32 \times 32$ $32 \times 32$

8. Padding in Deep CNN Architectures

Using Same padding inside convolution layers untangles feature extraction from spatial downsampling:

$$32 \times 32 \xrightarrow{\text{Conv (Same)}} 32 \times 32 \xrightarrow{\text{Pool}} 16 \times 16$$

Downsampling is placed solely under the control of pooling or strided operations, making multi-layer architecture depths simpler to compute.
