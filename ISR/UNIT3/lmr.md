1.QUERY EXPANSION : TECHNIQUES : synonym, knowledge, relevance, pseudo-relevance, semantic, search history; ADVANTAGES : improve recall, improve search result, handles vocabulary, useful in domains; LIMITATIONS : query drift, ambuiguity, computational cost, incorrect expansion terms

2.RELEVANCE FEEDBACK : TYPES : explicit, implicit, pseudo-relevance; ROCCHIO ALGORITHM : submit query, retrieve documents, collect feedback, calculate relevant document centroid, calculate non-relevant document centroid, modify the query, perform search again

3.QUERY OPTIMIZATION : TECHNIQUES : query expansion, stop word removal, stemming, lemmatization, spell correction, relevance feedback, query term weigthing, boolean query optimization

4.PATTERN QUERIES : wildcard, regex, fuzzy  STRUCTURAL QUERIES : title search, author search, html/xml, field-based search

5.APPROXIMATE ; EDIT DISTANCE : insertion, deletion and susbstitution (levenshtein distance)#minimuim number of changes 

6.CROSS LANGUAGE : WORKING : identify the query language, preprocess the query, translate or map the query; TECHNIQUES : machine translation, dictionary based translation, billingual thesaurus, neural translation;

7.CONVERSATIONAL SEARCH (chatbot) : MAIN CHARACTERISTICS : context awareness, natural language interaction, multi turn interaction, intent understanding, clarification; WORKING : receive query, analyze query, use conversation history, reform the query, retrieve information, generate response; DIFFERENCE : interaction, query style, context, user intent, follow up questions, clarrification, output, eg;

8.VOICE QUERIES : PROCESS : speech capture, speech recognition, query processing, information retrieval, ranking & answer selection, response generation

9.NQA : ARCHITECTURE : question input, question processing, question classification ( 5W), query reformulation, information retrieval, candidate answer extraction, answer ranking, answer generation; EG : WHO WROTE HARRY PORTER ?
