# 12. Comparison of Boolean, Vector Space, and Probabilistic Retrieval Models

## 1. Introduction

Information Retrieval uses different models to determine which documents are relevant to a user's query.

The three classical models are:

1. **Boolean Retrieval Model**
2. **Vector Space Model**
3. **Probabilistic Retrieval Model**

They differ mainly in **how they represent documents, match queries, and rank results**.

---

# 2. Boolean Retrieval Model

The **Boolean model** represents documents using the **presence or absence of terms** and uses logical operators such as:

* AND
* OR
* NOT

Example:

```text
machine AND learning
```

A document either **matches** the query or **does not match** it.

### Main idea

$$
\boxed{\text{Exact Boolean matching}}
$$

There is usually no degree of relevance in the basic model.

---

# 3. Vector Space Model

The **Vector Space Model (VSM)** represents documents and queries as **numerical vectors**.

Terms are usually assigned weights using **TF-IDF**.

Similarity between a document and query is commonly calculated using **cosine similarity**:

$$
\cos(\theta)=
\frac{D\cdot Q}
{|D||Q|}
$$

Documents can then be ranked according to their similarity scores.

### Main idea

$$
\boxed{\text{Vector representation + similarity}}
$$

---

# 4. Probabilistic Retrieval Model

The **Probabilistic Retrieval Model** ranks documents according to their estimated **probability of relevance** to the query.

The basic idea is:

$$
P(R=1\mid D,Q)
$$

where $R=1$ indicates that document $D$ is relevant to query $Q$.

A practical and widely used probabilistic ranking function is **BM25**.

### Main idea

$$
\boxed{\text{Estimate relevance probability and rank}}
$$

---

# 5. Detailed Comparison

| Feature                | Boolean Model    | Vector Space Model | Probabilistic Model                    |
| ---------------------- | ---------------- | ------------------ | -------------------------------------- |
| **Basic concept**      | Logical matching | Vector similarity  | Probability of relevance               |
| **Representation**     | Binary           | Numerical vectors  | Probabilistic/statistical              |
| **Term values**        | 0 or 1           | Weighted values    | Probability/statistical weights        |
| **Query operators**    | AND, OR, NOT     | Weighted terms     | Query terms with probability estimates |
| **Matching**           | Exact            | Partial            | Probabilistic                          |
| **Ranking**            | Usually no       | Yes                | Yes                                    |
| **Similarity/score**   | Boolean result   | Cosine similarity  | Relevance score/probability            |
| **Common weighting**   | None             | TF-IDF             | BM25/probabilistic weighting           |
| **Relevance degree**   | No               | Yes                | Yes                                    |
| **User control**       | High             | Moderate           | Moderate                               |
| **Complexity**         | Low              | Medium             | Medium–High                            |
| **Relevance feedback** | Limited          | Possible           | Important                              |
| **Example**            | `AI AND ML`      | Cosine similarity  | BM25                                   |
| **Main limitation**    | No ranking       | Limited semantics  | Probability estimation/assumptions     |

---

# 6. Example

Suppose we have the query:

```text
information retrieval
```

and three documents:

| Document | Content                          |
| -------- | -------------------------------- |
| D1       | Information retrieval techniques |
| D2       | Information systems              |
| D3       | Database management              |

### Boolean Model

Query:

```text
information AND retrieval
```

Only **D1** contains both terms.

Therefore:

$$
Result={D1}
$$

It simply determines whether each document satisfies the Boolean condition.

---

### Vector Space Model

The system calculates TF-IDF vectors and cosine similarity.

Suppose:

| Document | Cosine Similarity |
| -------- | ----------------: |
| D1       |              0.92 |
| D2       |              0.55 |
| D3       |              0.10 |

Ranking:

$$
D1>D2>D3
$$

D1 is considered most similar to the query.

---

### Probabilistic Model

Suppose the model produces:

| Document | Relevance Score |
| -------- | --------------: |
| D1       |            0.91 |
| D2       |            0.63 |
| D3       |            0.12 |

Ranking:

$$
D1>D2>D3
$$

The documents are ordered according to their estimated relevance.

---

# 7. Advantages and Disadvantages

## Boolean Model

### Advantages

* Simple and easy to implement
* Precise query control
* Efficient with inverted indexes
* Useful for exact searches

### Disadvantages

* No ranking in the basic model
* Small query changes can drastically change results
* Can return too many or too few documents
* Requires users to understand Boolean operators

---

## Vector Space Model

### Advantages

* Provides ranked results
* Supports partial matching
* TF-IDF captures term importance
* Cosine similarity is simple and effective

### Disadvantages

* Basic model ignores word order
* Limited understanding of semantics
* Synonyms and polysemy can cause problems
* Large vector spaces can require significant computation

---

## Probabilistic Model

### Advantages

* Provides relevance-based ranking
* Can incorporate relevance feedback
* Provides a strong theoretical basis for retrieval
* BM25 is highly effective in practical search systems

### Disadvantages

* Probability estimation can be difficult
* Some models make simplifying assumptions
* Requires appropriate statistical information
* More complex than Boolean retrieval

---

# 8. Key Differences

### Boolean

Answers:

> **"Does this document satisfy my query?"**

### Vector Space

Answers:

> **"How similar is this document to my query?"**

### Probabilistic

Answers:

> **"How likely is this document to be relevant to my query?"**

This is the easiest way to remember the difference.

---

# 9. Evolution of Retrieval Models

You can think of the models as progressing from simple matching toward increasingly sophisticated ranking:

```text
Boolean
   ↓
Exact matching
   ↓
Vector Space
   ↓
Similarity-based ranking
   ↓
Probabilistic
   ↓
Relevance-based ranking
```

Modern systems additionally use **neural/dense retrieval** and **BERT-based reranking** to capture semantic meaning.

---

# 10. Conclusion

The three retrieval models have different approaches to finding relevant documents:

$$
\boxed{
\begin{aligned}
\text{Boolean} &\rightarrow \text{Logical Matching}\
\text{Vector Space} &\rightarrow \text{Similarity Ranking}\
\text{Probabilistic} &\rightarrow \text{Relevance Ranking}
\end{aligned}
}
$$

The **Boolean model** is simple and precise, the **Vector Space Model** provides similarity-based ranking, and the **Probabilistic Model** ranks documents based on estimated relevance.

### Exam memory trick

| Model             | Remember as     |
| ----------------- | --------------- |
| **Boolean**       | **Match**       |
| **Vector Space**  | **Similarity**  |
| **Probabilistic** | **Probability** |

**Match → Similarity → Probability** — that's the core comparison.
